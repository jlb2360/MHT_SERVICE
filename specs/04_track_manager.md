# Spec 04: Track Manager

## Objective
Implement a track manager which creates, updates, and destroys track nodes depending on a new set of measurements. This should be a python class.

## Interfaces & Contracts

### 1. State Representation
*   **Registry (`registry`):** dictionary of [int, `TrackNode`] which is denoted by the track_id.
*   **Active Leaves (`active_leaves`):** Set of IDs which represent the current time step's hypotheses.
*   **Trees (`trees`):** dictionary of [int, Set[int]] which groups the active leaves by their original root ID
*   **Next Node ID (`next_node_id`):** Unique ID counter
*   **Next Tree ID (`next_tree_id`):** Unique ID counter
*   **Velocity Assumption (`vel_assumption`):** NumPy array of shape `(2,)` representing `[x_velocity, y_velocity]`.
*   **Initial Covariance (`init_cov`):** NumPy array of shape `(2, 2)` representing the **uncertainty in the initial velocity assumption**.
*   **Q Variance (`q_variance`):** float representing the **process noise** for the tracker.
*   **Prune Threshold (`min_score`):** float representing the **minimum log-likelihood** that a leaf can have.
*   **N Steps (`n_steps`):** int representing the **number of steps looked back for pruning**.\
*   **Price Update Size (`alpha`):** float representing the step size to shift the penalty for the lagrangian relaxation algorithm.

### 2. Required Functions / Methods
*   **`process_scan(self, measurements: Dict[int, np.ndarray], Rs: Dict[int, np.ndarray], dt: float, timestamp: float, gate_threshold: float, p_d: float, lambda_fa: float) -> None`**
    * process the current set of measurements by going through the following steps
        1. Predict
        2. Spawn new hypotheses for missing detection
        3. Spawn new hypotheses based on Gate
        4. Spawn new roots for measurements that were not attached to any current hypotheses 
    * This process should spawn a new hypothesis for each track as if they missed a detection.
    * step 3 should also be the step where it is figured out which measurements did not get associated with a track.
*   **`_add_node(self, node: TrackNode, new_leaves: Set[int]) -> None`**
    * add a new node to a current root
*   **`_create_new_root_track(self, meas_id: int, measurement: np.ndarray, R: np.ndarray, timestamp: float)`**
    * add a new root to the tree from measurement and covariance that did not get associated with any current hypotheses
    * a new covariance is generated by taking R, the measurement covariance, and init_cov for the uncertainty in x_velocity and y_velocity.
*   **`prune_threshold(self)`**
    * method to prune all leaves if the likelihood score has dropped below the threshold of min_score
*   **`prune_n_scan(self)`**
    * prune the leaves by locking in the best history for a hypotheses n_steps ago.
*   **`get_best_global_hypothesis(self) -> List["TrackNode"]`**
    * use the **lagrangian relaxation** approach for finding the best global hypothesis. 
        * look at the adjusted score $S_i - \sum_{j=1}^M A_{ij}\lambda_j$ if the adjusted score is positive then it is displayed otherwise it is rejectied.
            * i is the loop of track hypotheses
            * j is the measurements in a scan
            * $A_{ij}$ is the binary matrix where it is equal to 1 if track i claims measurement j and 0 otherwise.
        * use **the subgradient optimization loop** adjusting the penalty size by self.alpha.
            * $\lambda_j^{new} = max(0, \lambda_j^{old} + self.alpha * g_j$
                * $g_j = 0$: The measurement was used exactly once
                * $g_j < 0$: The measurement was not used at all
                * $g_j > 1$: The measurement is over-subscribed 
        * if looped 50 times then use the current adjusted scores in the **greedy algorithm** for finding the best global hypothesis.
*   **`_delete_branch(self, node_id: int)`**
    * recursively delete a node and all descendents
